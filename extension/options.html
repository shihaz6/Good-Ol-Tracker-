Good ol Tracker

Connection

Paste the token from data\token.txt in the Good ol Tracker folder. The file is created the first time the desktop tracker runs.

Recording

Brave will ask to "read and change data on all websites". That's required to read page text; the extension never changes pages. Untick to revoke. When off, content is read only on YouTube videos, Medium articles and Reddit threads.

Never read content on these sites

One domain per line; covers subdomains. Time spent there is still tracked, only page content is skipped. Any site with "bank" in its name is always skipped.

What this extension records

  • Every site: URL, tab title, time spent and how far you scrolled.
  • Searches on any site (the search text and which site), read from the URL.
  • Page content (title, headings, main text, max 3,000 characters) per the settings above.
  • Never: what you type, pages with password or card fields, blocked sites, incognito tabs.
  • Everything is sent only to this PC (127.0.0.1). Full page text is deleted after 60 days.
