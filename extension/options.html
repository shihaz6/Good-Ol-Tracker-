Good ol Tracker

Paste the token from data\token.txt in the Good ol Tracker folder. The file is created the first time the desktop tracker runs.

What this extension reads

  • Every site: the active tab's URL, title and time spent (not page content).
  • Page content only on YouTube videos, Medium articles and Reddit threads (never if the page has a password field).
  • Google searches: the search text from the URL.
  • Incognito tabs are never tracked. Everything is sent only to this PC (127.0.0.1).
