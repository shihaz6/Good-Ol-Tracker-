Offline time

Phone

The Good ol Tracker Android app sends which apps you used and when (never what's inside them) to this PC over your hotspot or Wi-Fi. It catches up on anything missed.

How to connect a phone
  1. Install the app (android\GoodOlTracker.apk) and allow Usage access when it asks.
  2. Connect the PC to the phone's hotspot (or the same Wi-Fi), then tap Connect to PC in the app.
  3. A request with a 4-digit code appears here: allow it if the code matches the phone.
  4. Once, on the PC: set the hotspot network to Private (Settings → Network & internet → Wi-Fi → the hotspot → Network profile type) and run phone_firewall.ps1 as administrator.

Limits, bedtime, schedule and goals

The same rules on both devices. A limit is one daily budget for the app and its website (Facebook app + facebook.com count together; study videos don't count). Bedtime locks social and video apps on the phone and the same sites in Brave. The phone keeps a copy, so it works away from the PC too.

How to get a Gmail App Password
  1. Turn on 2-Step Verification for your Google account (required for App Passwords).
  2. Open myaccount.google.com/apppasswords, name it "Good ol Tracker", click Create.
  3. Copy the 16 letters into the box above and Save. Revoke it there any time.

Emails contain totals, top app/site names, topic words and the AI summary. Never page text, titles, URLs or your searches.

Fix categories

Pick a category and it's saved as a rule in categories.json. All your history is recategorised right away, and you can undo it. Groq (AI) decides Unsure pages on its own and suggests categories for new sites and apps; nothing is sent for banks, password managers or WhatsApp.
